# ML research sources

- Nho, Lim and Kwon (2020), *Cluster-Analysis-Based User-Adaptive Fall Detection
  Using Fusion of Heart Rate Sensor and Accelerometer in a Wearable Device*.
  [Read the paper](https://doi.org/10.1109/ACCESS.2020.2969453).
- [HIFD dataset](https://github.com/nhoyh/HR_IMU_falldetection_dataset): the sensor recordings used in this project.
- [InceptionTime](https://github.com/hfawaz/InceptionTime): the model design used as the starting point for the current network.

The supplied paper is kept locally as `fall-detection-nho-2020.pdf` in this
folder. It is excluded from Git. The links above are also available in a new
copy of the repository.
