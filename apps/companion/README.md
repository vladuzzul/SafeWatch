# Aplicatia companion

Aici va fi implementata interfata aplicatiei: asocierea cu ceasul, prezentarea
starii dispozitivului si fluxul prin care utilizatorul gestioneaza o alerta.

Platforma si framework-ul nu au fost alese inca. Directorul contine numai
aceasta delimitare, nu o aplicatie functionala.

Aplicatia nu trebuie sa importe codul de antrenare. Integrarea va folosi
contractele din `shared/contracts/`. Pentru o aplicatie nativa sau web, se va
alege ulterior intre inferenta exportata pe dispozitiv si apelarea unui serviciu
care utilizeaza pachetul Python `safewatch_ml`.
